# Udhaar Kaatha

## Overview

Digital Udhaar Management System for Shopkeepers and Customers with online payment support using Razorpay.

## User Roles

- Shopkeeper
- Customer

## Shopkeeper Features

- Register/Login
- Add Customers
- Set Udhaar Limits
- Add Transactions
- Record Payments
- View Customer Ledger
- Dashboard Analytics
- Notifications

## Customer Features

- Register/Login
- View Pending Udhaar
- View Shop-wise Balance
- View Payment History
- Receive Notifications
- Pay Online via Razorpay

## Project Flow

### Shopkeeper

Login → Add Customer → Add Transaction → Udhaar Created → Customer Balance Updated → Ledger Updated

### Customer

Login → View Pending Amount → Pay via Razorpay → Payment Success → Balance Updated → Notification Generated

## Payment Flow

Pay Now → Create Razorpay Order → Complete Payment → Verify Payment → Update Balance → Create Transaction Record
